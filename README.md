# Grocery Market Simulation

## Description

This project is a C++ program that simulates a grocery market. The program uses user input, calculations, structures, and formatted output to model basic grocery market operations.

## Concepts Used

- C++
- Structs
- Variables and constants
- User input and output
- Calculations
- Conditional statements
- Loops
- Formatted output

## Purpose

This project was completed as part of my C++ programming coursework to practice fundamental programming concepts and develop a program that simulates a grocery market.

## Academic Project

This project was created for coursework and demonstrates my application of C++ programming concepts.
